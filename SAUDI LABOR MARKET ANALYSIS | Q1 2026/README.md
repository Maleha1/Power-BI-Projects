# SAUDI LABOR MARKET ANALYSIS | Q1 2026

## Overview

An interactive Power BI dashboard analyzing Saudi Arabia's labor market statistics for Q1 2026 using official data from the General Authority for Statistics (GASTAT).

## Project Workflow

The project workflow included:

1. Working with the original Excel dataset.
2. Using Python to prepare, organize, and process the required data.
3. Importing the prepared data into Power BI.
4. Building the data model using dimension tables and relationships.
5. Creating DAX measures for key performance indicators (KPIs).
6. Designing an interactive dashboard to explore labor market indicators.

## Dashboard Pages

### 1. General Labor Market Indicators
- Unemployment rates and trends
- Unemployment by gender and nationality
- Key labor market indicators

### 2. Geographic Distribution of Labor Force and Unemployment
- Unemployment rate by region
- Labor force distribution by region
- Geographic comparison across Saudi regions

### 3. Education and Wages
- Unemployment by education level
- Average wages by education level
- Labor force distribution by age
- Working hours
