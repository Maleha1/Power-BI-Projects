# Sales Analysis Dashboard

## Overview

A sales analysis dashboard developed using Microsoft Power BI to analyze sales performance, profitability, transactions, and business trends.

The dashboard provides an interactive view of sales data across different years, quarters, months, cities, stores, and product categories.

## Dashboard

The dashboard includes key performance indicators and interactive visualizations to help understand overall sales and profit performance.

### Key Performance Indicators

* **Total Profit:** $3.78M
* **Average Profit:** $1.89K
* **Total Sales:** $10.08M
* **Transactions:** 1,998

### Visualizations

* **Sales by City** – Displays sales distribution across different cities.
* **Profit by Store** – Compares profit performance across stores.
* **Profit by Product** – Shows profit generated by different product categories.
* **Sales by Month** – Illustrates monthly sales trends.
* **Interactive Filters** – Allows users to filter the dashboard by:

  * Year
  * Sale Size
  * Quarter
  * Month

## Analysis Focus

The dashboard focuses on:

* Sales performance
* Profitability analysis
* Transaction analysis
* Monthly sales trends
* Sales distribution by city
* Profit comparison across stores
* Product profitability
* Interactive exploration of sales data

## Tools

* Microsoft Power BI
* Power Query
* DAX

## Project Objective

The objective of this project is to transform sales data into an interactive dashboard that provides clear insights into sales and profitability performance and supports data-driven analysis.
